# StudyFlow

StudyFlow is a simple academic planner created for students. It helps users manage tasks, class schedules, notes, study sessions and GPA in one place.

## Features

- Task planner with LocalStorage
- Weekly timetable
- Digital notes with word counter
- Download notes as text files
- GPA calculator
- Pomodoro focus timer
- Dark and light mode
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Project Purpose

This project was originally created as a first semester ICT project. It was later redesigned and improved to make the interface cleaner and add more useful features.
